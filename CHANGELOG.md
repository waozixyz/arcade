# Arcade changelog

## 0.3.0

- Import a PGN game or FEN position into Chess study, with player details and the correct starting move number.
- Review and analyze imported positions, then copy them back to other chess tools.
- Keep an imported study while switching between Chess tabs, with clear feedback for invalid input.

## 0.2.1

- Pushy adds Continue and a level selector with completion marks.
- Completing a Pushy puzzle unlocks the next one and keeps progress across restarts.

## 0.2.0

- Chess adds hints, turn takebacks, an Expert opponent, board coordinates and flipping.
- Study a game move by move, try variations, analyze positions and copy PGN or FEN.
- Game updates retain their translated text across compatible Arcade and Inner Breeze hosts.

## 0.1.2

- Open Pushy from the game library with the original Classic layouts, new
  graphics, keyboard and on-screen controls, restart, and an object guide.
- Continue the same Pushy position after leaving the game or restarting.
- The two shadow puzzles at 165–166 can be viewed but remain paused while
  their original rules are being verified.

## 0.1.1

- Choose games from a grid of cards with real game previews.
- Return to the library with the top Back button and continue the same game.
- Chess uses one game package across Arcade and Inner Breeze, with its own
  translations and compatibility checks that preserve existing games.

## 0.1.0

- Open Chess from Arcade and play the computer at three difficulty levels.
- Continue a saved local game after closing and reopening Arcade.
- Chess remains available in Inner Breeze for thoughtful play.
